# High-Performance Retail Inventory Analyzer

A backend utility designed to process massive Point of Sale (POS) datasets and navigate complex retail inventory hierarchies simultaneously. 

## 🚀 Core Technologies
* **Pandas:** High-speed aggregation of POS datasets.
* **Tree Traversal (BFS / DFS):** Navigates the $O(V+E)$ category tree.
* **Deep Threading:** Thread pools for concurrent data processing.
